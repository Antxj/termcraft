# TermCraft — Parity Checklist

Target: **1:1 parity** with MobaXterm (same menus, dialogs, shortcuts, settings
and behavior; own icons and branding). Seeded from the public feature page and
documentation; to be refined with inventories generated from the reference
copy in `reference/`. See [CLEAN_ROOM.md](CLEAN_ROOM.md).

Legend: `[x]` done · `[~]` partial · `[ ]` not started
Priority: **P0** MVP · **P1** next · **P2** later · **P3** nice-to-have

> A checked box means the feature is wired and tested, not that behavior is
> identical to the original. Behavior gaps are tracked as issues.

**Ground truth:** [inventory/](inventory/README.md), generated by
`cargo xtask inventory` from MobaXterm 26.5: 64 forms, menus with shortcuts,
the main toolbar, and 15 session types with 252 parameters. Rows below are
refined against it.
